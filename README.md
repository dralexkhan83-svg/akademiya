# Академия ортопедов Dental Profi

Сайт с учебными материалами Академии: блоки 1–6.

Страницы собираются скриптом `_build/build.py` из папки «Академия» (Word, PDF, Excel, схемы).
Папка «02 Ученики» и любые данные пациентов на сайт не попадают: сайт открытый.

Пересборка: `python3 _build/build.py /путь/к/Академия`
